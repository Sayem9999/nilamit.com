# 🏛️ KAIROS: Strategic Memory Core

> Last Updated: April 29, 2026

**KAIROS** is the permanent knowledge management system for Nilamit. It ensures continuity between AI coding sessions by maintaining a single source of truth for architectural decisions, rules, and lessons.

## 🧭 Memory Structure
The core logic resides in the [`/memory`](file:///c:/nilamit.com/memory/) directory:

- **[Rules](file:///c:/nilamit.com/memory/rules.md)**: Hard constraints for UI, Security, and Trust protocols.
- **[Architecture](file:///c:/nilamit.com/memory/architecture.md)**: Technical design patterns and system boundaries.
- **[Decisions](file:///c:/nilamit.com/memory/decisions.md)**: Historical log of WHY things were built a certain way.
- **[Lessons](file:///c:/nilamit.com/memory/lessons.md)**: Anti-patterns to avoid and verified solutions.

## 🔄 Lifecycle Protocols
- **Session Memory**: In-turn tracking of immediate objectives and progress.
- **[Auto Dream](file:///c:/nilamit.com/auto_dream.md)**: Post-session reflection and state synthesis.
