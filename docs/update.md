# 📢 Nilamit Platform Updates

## [v0.3.1] - 2026-04-12
### 🚀 Added (Regional & Social Filtering)
- **Geographic Areas**: Implemented neighborhood-specific filtering for Dhaka (Mirpur, Banani, Gulshan, etc.).
- **Social Circles**: Launched "Private Circles" featuring an invite-only membership model for high-trust trading.
- **Circle-Aware Feed**: Automated backend privacy filtering that hides Circle auctions from non-members.
- **Home Area Explorer**: Added `AreaQuickLinks` to the landing page for hyper-local discovery.

### 🛡 Legal & Compliance
- **[legalframework.md]**: Published the complete legal framework (Digital Commerce Guidelines 2021).
- **Redressal SLA**: Codified the 72-hour dispute resolution requirement.
- **Data Retention**: Enforced the 6-year data retention mandate in the spec-kit.

---

## [v0.3.0] - 2026-04-12
### 🔔 Interaction (Smart Alerts)
- **Real-time Notifications**: Integrated `ending-soon` Pusher events with custom toast notifications.
- **Closing-Soon Cron**: Automated the task to identify and push alerts for auctions closing within 30-60 minutes.

### 🛡 Admin & Trust
- **Admin Verification**: Enabled manual verification toggles for sellers in the Admin Dashboard.
- **Verified Seller Badges**: Deployed blue shield icons for verified vendors to drive trust.

### 💎 UI/UX Polish
- **Stats Bar**: Added a live platform metrics bar (Total Users, Bids, Auctions).
- **Hero Update**: Replaced hardcoded numbers with live, dynamic user counts.
- **[spec-kit.md]**: Inaugurated the project "Gold Standard" technical specification.
